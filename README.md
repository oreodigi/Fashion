# NOOLAM · Silk Saree Fashion Showcase

Interactive editorial saree showcase reconstructed from the publicly shared design briefs and screenshots in [alagappan567/noolam-saree-showcase](https://github.com/alagappan567/noolam-saree-showcase). This is an independently implemented frontend; the reference repository does not contain application source code.

Target: `https://tejum.in/fashion/`. Built with Vite + React and deployed as a static app to cPanel. Demo product listings, prices, wishlist and bag are illustrative; no checkout backend or real inventory connection.

Photography: sample imagery for design demonstration. Replace with owned/approved product photography before commercial launch.
